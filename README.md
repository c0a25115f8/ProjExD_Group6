# プロジェクト演習II テーマD グループ06

### ■ ゲーム概要
**タイトル：アイテムキャッチ・パニック**
画面上部から降ってくるアイテムをプレイヤーを操作してキャッチする2Dアクションゲーム。
本プロジェクトでは、**「完全に動作する基本ゲームシステム」に対して、各メンバーが高度な追加機能をプラグイン形式で実装し、ゲーム性を拡張していく**手法をとる。

**【基本操作とルール】**
- **操作**: 十字キー（左右）でプレイヤーを移動。
- **勝利条件**: 60秒間でできるだけ多くのアイテムをキャッチし、ハイスコアを目指す。

### ■ 実行環境・必須ライブラリ
- Python 3.x
- pygame

### ■ 実行方法
リポジトリをクローン後、ターミナルで以下のコマンドを実行。
`python main.py`
※画面サイズは 800x600、FPSは 60 で固定。

---

### ■ 【重要】共同開発のルール（全員必読）
1. **`main.py` の基本ロジックは破壊しない**
   各自の拡張機能は必ず `feature_*.py` という別ファイルにクラスとして実装する。`main.py` にはモジュールのインポートと、各ループ内でのメソッド呼び出し（数行）のみを追記すること。
2. **ブランチ運用の徹底**
   作業は必ず `main` ブランチから自分の作業ブランチ（例: `feature/boss`）を切って行う。
